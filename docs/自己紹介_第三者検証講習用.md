## 【Page 5】 今日、皆さんに伝えたいこと

### QAって、実はめちゃくちゃ面白い仕事です

```
❌ よくある誤解
  「テストって、ただ操作するだけでしょ？」

✅ 実際は
  ユーザーの代わりに「おかしい」を見つける仕事
  品質という視点で、プロダクト全体に影響できる
  エンジニア・デザイナー・企画と全員と話せる
```

---

### 若いうちに身につけてほしいこと 3つ

1. **「なぜ？」を問い続ける習慣**
   バグは現象ではなく、原因を探ることが大事

2. **記録する力**
   再現手順、環境、状況を正確に言語化できると一気に信頼される

3. **報告・連絡・相談を怖がらない**
   問題を早く共有した人が、チームのヒーローになれる
