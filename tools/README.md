# Tools

Reusable helper scripts for CTF work.

## Scripts

- `new_challenge.py`: create a new challenge directory from templates.
- `prepare_seccon_beginners_2026.ps1`: create SECCON Beginners CTF 2026 workspace folders and starter notes.
- `check_environment.ps1`: check common Windows CTF tools and Python packages.
- `setup_ctf_windows.ps1`: install common Windows CTF tools with winget.
- `install_ghidra_windows.ps1`: install Ghidra from the official GitHub release and add a `ghidraRun` shim.
